# Ibrahim El Garhy — broker site

Starting point: a copy of the VIBE Real Estate build (Muhaabdo/the-polygon-s, Oct 2026).
Everything VIBE-specific (brand, phone, emails, GTM/Ads IDs, Apps Script URL, projects, prices,
images, generated HTML) is placeholder content to be replaced for this client.

Follow docs/RUNBOOK.md for the whole job: inputs, page structure, lead flow, tracking, SEO, AEO,
campaign file, QA and launch.

- Content and prices live in tools/site_data.py and tools/pages_data.py; pages are generated by
  `python tools/build.py`. Never hand-edit generated HTML.
- Local preview: `python tools/serve.py` (port 8080).
- Campaign files: `python tools/ads/build_campaign.py`.
- Raw price sheets stay out of git (data/ and *.xlsx are ignored).
- Deploy target: Hostinger, pulling `main` via hPanel GIT (no build step; generated HTML is committed).
